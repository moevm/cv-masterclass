# cv-masterclass

Материалы и задания для мастер-класса «Компьютерное зрение для начинающих» (Python + OpenCV).
Задания рассчитаны на Linux

## Подготовка (один раз, ~5 минут)

1. Скачайте архив с заданиями: зелёная кнопка **Code** → **Download ZIP**.
2. Распакуйте архив в свою папку, например `~/MK_CV`.
3. Откройте Терминал в папке с заданиями (правый клик по папке → «Открыть в терминале»)
   и выполните:
   ```bash
   bash install.sh
   ```
   Если попросят пароль -- введите пароль от компьютера (символы при вводе не видны, это нормально).
4. Скрипт сам установит всё нужное (Python, pip, OpenCV, numpy).

## Как работать с заданиями

1. Откройте VS Code → **File → Open Folder** → выберите папку с заданиями.
2. Откройте файл задания (например, `1_task/studying.py`).
3. Найдите строчки со словом `TODO` и допишите код по подсказкам.
4. Запустите программу в терминале: `python3 1_task/studying.py`.
5. Окно с картинкой закрывается нажатием любой клавиши.
